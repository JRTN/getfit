# M0 — Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A buildable, CI-checked multi-module Android project: every module from the design exists (empty), the app launches into five bottom tabs plus Settings, has a light/dark theme stub, writes crash logs, and debug and release builds install side by side.

**Architecture:** A `build-logic` included build holds eight convention plugins, so each module's build file is a few lines. `:app` owns `MainActivity`, the Hilt `Application`, a `TopLevelBackStack` and the Navigation 3 `NavDisplay`. Each `:feature:*` module contributes a `NavKey`, a placeholder screen and an entry-provider extension. A Konsist test module enforces the layer rules from day one.

**Tech Stack:** Gradle 9.8.1, AGP 9.4.1 (built-in Kotlin), Kotlin 2.4.21, KSP 2.3.12, Hilt 2.60.1, Compose BOM 2026.09.00, Navigation 3 1.2.0, kotlinx.serialization 1.11.0, JUnit 5.14.4 / JUnit 4.13.2, AssertK 0.28.1, Konsist 0.18.1, detekt 2.0.0-alpha.6, ktlint-gradle 14.2.0, Dependency Analysis Gradle Plugin 3.9.0.

**Spec:** `docs/initial_design.md` (sections: Platform, SDK levels and tooling; Module architecture; Build infrastructure; Code conventions; v1 milestone plan → M0)

## Global Constraints

- `minSdk` 34, `targetSdk` 37, `compileSdk` 37 (amended from 36 during Task 2 by user decision; Compose 1.12 requires compileSdk 37).
- Release `applicationId` `com.jrussell.fitness`; debug `com.jrussell.fitness.debug`; display name "GetFit" / "GetFit (Debug)" from the `app_name` string resource.
- Namespace convention: `com.jrussell.fitness.<module path with dots>`, e.g. `com.jrussell.fitness.feature.nutrition`.
- Kotlin in explicit style: explicit types, block bodies, named classes.
- Version catalog `gradle/libs.versions.toml` is the single source of versions; type-safe project accessors (`implementation(projects.core.domain)`).
- Configuration cache and build cache enabled from the first commit.
- KSP only; no kapt.
- Pure-Kotlin modules (`:core:model`, `:core:domain`, `:core:projection`, `:core:importers`) apply `app.jvm.library` and depend on no Android module.
- No feature module depends on another; cross-feature navigation is wired in `:app`.
- Edge-to-edge is mandatory: `enableEdgeToEdge()`; insets handled by `Scaffold`.
- No `onBackPressed()`; back handling uses `BackHandler` / `PredictiveBackHandler` (Navigation 3's `NavDisplay(onBack = …)`).
- `versionCode` derived from the git commit count; `versionName` semver set by hand (start `0.1.0`).
- R8 enabled on release from the first release build.
- Every user-visible string is a resource.
- The release keystore lives outside the repository and is never committed.
- CI: JDK 17; runs `./gradlew check`, `./gradlew buildHealth`, `./gradlew assembleDebug`; uploads test and lint reports.

## Calls made in this plan (not in the design doc)

1. **Konsist lives in a 23rd module, `:architecture-tests`** (JVM, JUnit 5), because Konsist scans the whole repository and fits no inventory module.
2. **detekt 2.0.0-alpha.6** (plugin id `dev.detekt`) instead of 1.23.8. The 1.23.x Gradle plugin predates AGP 9's removal of the legacy `BaseExtension`.
3. **The custom detekt rules (no `Color(` literal, no hardcoded `Dispatchers.*`, no `fallbackToDestructiveMigration`) move to M1**, when the design system, dispatcher module and Room code they guard first exist.
4. **Unused declared dependencies only warn in Dependency Analysis during M0.** The feature convention plugin adds the standard `:core:*` dependencies to modules that are still empty, so failing on them would fail every build. The other issue types (used-but-undeclared, wrong configuration) fail the build. Restore failing on unused dependencies in M1.
5. **Tab icons come from `material-icons-core` 1.7.8 as placeholders** (Today=Home, Nutrition=List, Training=PlayArrow, Body=Person, Trends=DateRange, Settings=Settings). Proper Material Symbols arrive with the M1 design system.
6. **The tab back stack lives in a Hilt `MainViewModel`**, so it survives rotation. After process death it starts again at Today, which is acceptable for M0.
7. **ktlint, not ktfmt**, with `ktlint_code_style = android_studio`.
8. **No Gradle JVM toolchains.** Gradle runs on whatever JDK ≥ 17 launches it (Android Studio's JBR 25 locally, Temurin 17 in CI). Kotlin `jvmTarget` and Java `compileOptions` target 17.
9. **API 37 is available locally** (`platforms/android-37.0`), but the design fixes `compileSdk`/`targetSdk` at 36. AGP downloads platform 36 on the first build. Lint's `OldTargetApi`, `GradleDependency`, `AndroidGradlePluginVersion` and `NewerVersionAvailable` checks are disabled so that decision doesn't produce noise.
10. **The `Logger` interface from code convention 10 is deferred to M1.** M0 ships only the uncaught-exception crash-log file.

## Review Focus

1. Pressing back at the root of a non-Today tab should land on Today, not exit the app. This is pinned in Task 6 (`removeLast_atRootOfOtherTab_returnsToStartTab`).
2. If writing the crash log fails (an unwritable directory or a full disk), the app must still crash normally through the previous handler, without hanging or swallowing the crash. Pinned in Task 7 (`uncaughtException_whenDirectoryUnwritable_stillDelegates`).
3. Crash logs must not grow without limit after repeated crashes; only the newest 10 are kept. Pinned in Task 7 (`uncaughtException_keepsOnlyNewestTenFiles`).
4. Debug and release must really be separate apps with separate data. Pinned in Task 2 (an `apkanalyzer` application-id check) and in Task 9 (side-by-side install).
5. A build without git history (a fresh clone in CI with a shallow checkout, or a source zip) must not fail on `versionCode`. It falls back to 1. Pinned in Task 2 (build from a copy without `.git`), and CI uses `fetch-depth: 0` (Task 8).

class LayerRulesTest {
    private val pureModules: List<String> = listOf("core/model", "core/domain", "core/projection", "core/importers")
    private val featureNames: List<String> = listOf("today", "nutrition", "training", "body", "trends", "settings")

    @Test
    fun pureModules_importNoAndroid() {
        Konsist.scopeFromProduction()
            .files
            .filter { file: KoFileDeclaration -> pureModules.any { module: String -> file.path.contains("/$module/") } }
            .assertFalse { file: KoFileDeclaration ->
                file.imports.any { import: KoImportDeclaration -> import.name.startsWith("android.") || import.name.startsWith("androidx.") }
            }
    }

    @Test
    fun featureModules_doNotReferenceOtherFeatures() {
        featureNames.forEach { feature: String ->
            Konsist.scopeFromModule("feature/$feature")
                .files
                .assertFalse { file: KoFileDeclaration ->
                    file.imports.any { import: KoImportDeclaration ->
                        featureNames.filter { other: String -> other != feature }

                }
        }
    }
}
